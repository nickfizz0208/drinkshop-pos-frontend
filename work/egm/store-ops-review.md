# 日結與報廢：聚焦設計審查與驗證

## 執行範圍

使用 EGM review-loop，單一 fresh-context Design Critic、一次初審及唯一一次聚焦複查，未執行完整五階段流程，也不宣稱多輪收斂。審查者確認已讀 bundled persona、feature-spec-standard、規格與指定前後端來源；不讀聊天／記憶、不遞迴委派、不修改實作。

## 初審發現與處理

1. **Major / 原料 POST 前持久化**：沒有 requestId 的原料 API 若先 POST 再記標記，重載會漏掉不明結果。已修正為先成功保存員工隔離的標記，再允許送出；儲存失敗不 POST。複查確認此項已解決。
2. **Major / 跨午夜確認**：後端按執行日扣料，昨日確認不能延用至今日。已加入提交時日期重驗，過期確認直接作廢；不明結果須成功讀取紀錄才可人工解除。

## 唯一一次聚焦複查

複查仍提出 **Major / 延後核對漏中間日期**：午夜送出、隔兩天才核對，僅查送出日與今天會漏掉次日。已依具體證據修正為完整日期區間，最多 31 天；確認解除前再驗日期完整及未跨午夜。加入「隔兩日核對包含中間日」和「核對後跨午夜不能解除」回歸測試。依使用者上限，修正後沒有再開第三輪審查；修正證據來自程式及測試，不聲稱 reviewer 再度批准。

複查未發現現金計算、CLOSED 保存值、操作確認、本機 pending guard 等範圍的其他實質問題。

## 驗證結果

- 前端 **72 個測試通過**、正式 build 通過、無模板警告。
- 其中新增 API 契約測試及 20 個營運測試，涵蓋現金／非現金／退款／未知欄位、404／503、關班限制、日期切換、重整標記、儲存失敗、隔日／延後核對、員工隔離、過時回應，以及實際模板選單與 disabled 條件。
- UI 使用既有茶綠 token 與元件封裝；未登入入口實際開啟，375px 檢查無水平溢位（clientWidth 與 scrollWidth 同為 375px）。登入後表單與寫入使用隔離 API 替身驗證。
- 尚無原料報廢 server requestId，人工核對是明確限制；超過 31 天待核對會保持鎖定。
